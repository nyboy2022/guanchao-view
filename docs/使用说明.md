# 观潮看盘 使用说明

## 详细用法
- K线 + 成交量，最新价虚线和收盘倒计时
- 周期：1分 / 5分 / 15分 / 30分 / 1时 / 4时 / 日 / 周 / 月 / 今年至今
- 缩放平移：滚轮缩放；按住拖动平移；拖右侧价格轴纵向缩放、双击复位；拖底部时间轴横向缩放；"⇥ 最新"回到最新
- 往左拖会自动加载更早的历史数据
- 指标可以自定义：点「指标」打开面板（所有图共用一套指标）
  - 主图：MA、EMA、WMA 加权均线、布林带、VWAP（每个交易日重新计算）、SAR 抛物线
  - 副图：VOL 成交量（带两条均量线）、RSI、MACD、KDJ、ATR、OBV、CCI、WR
  - 同一种指标能加好几条，例如 MA5、MA10、MA60；每条都能改参数、改颜色、勾选隐藏、点 × 删除
  - 改动立即生效，并且会自动保存；「恢复默认」会回到 MA20/50/200 + RSI14
- 多图：顶部「1图 2 4 6 8」切换，同时看多只。先点一下某个图（黄框表示当前图），再点自选里的品种，就换成这个品种。指标所有图共用，周期每个图单独设置
- 画线：趋势线、射线、水平线、平行通道、矩形、斐波那契回撤、斐波那契扩展、文字标注、测量；可选中、拖动端点、整体移动；Delete 删除，Esc 取消
  - 平行通道：先拖出主线，再移动鼠标定通道宽度，点一下完成
  - 斐波那契扩展：依次点 A（起点）、B（终点）、C（回调点），显示 0.618 / 1 / 1.618 / 2.618 等目标位
  - 文字标注：点一下放置并输入文字，双击可以修改
  - 测量：拖一下，显示涨跌额、涨跌幅、K线根数和经过的时间
- 右键菜单：在K线图空白处右键，可以在这个价位设警报、画水平线、加文字标记、复制价格、回到最新、重置缩放、切换这个图的周期和K线样式、加对比、开关成交量分布和财报标记。在画线上右键，可以改颜色、设警报、锁定（锁定后不会被拖动）、复制一份、删除
- 多图时每个图的周期是独立的：先点一下某个图（橙色边框），再点顶部周期，只改这个图；图左上角会标出它自己的周期。布局保存也会记住每个图的周期
- 多图联动：多图时顶部的 🔗 打开后，鼠标在一个图上移动，其它图同一时间位置也会出现竖线并显示那根K线的数值；缩放、平移也会同步（周期不同的图只对齐时间，各自保留缩放）
- 筛选器：自选右上角的 🔍。按今日涨跌幅、放量、站上/跌破均线、突破均线、创 N 日新高/新低、RSI 扫描当前列表、所有列表或自己输入的代码；点结果在图里打开，也可以把结果存成一个新列表
- K线样式：顶部下拉框可切换 蜡烛 / 空心蜡烛 / 平均K线（Heikin Ashi）/ 折线 / 面积
- 对比叠加：「指标」面板里输入代码（如 SPY、QQQ、BTC-USDT）点添加，最多 3 个；按可见区第一根K线对齐成同一起点，图例显示各自涨跌幅
- 成交量分布：「指标」面板里勾选，图右侧显示按价位统计的成交量，最密集的价位标 POC
- 布局保存：顶部「▦ 布局」。把几个图、每个图的品种、周期、指标、K线样式、对比、成交量分布存成一个布局，起个名字；以后点名字一键切换（会自动切到对应的市场）。可以覆盖、改名、删除（删除要点两次）
- 财报 / 分红 / 拆股标记（只有美股）：「指标」面板里勾选，图底部出现圆点：E 财报（绿色 = 超预期，红色 = 低于预期）、D 分红（除息日）、S 拆股。鼠标移上去看详情
  - 分红和拆股来自 Alpaca 公司行动接口，用你已经填的 Alpaca Key
  - 财报日 Alpaca 不提供。在 ⚙ 设置里填一个 Alpha Vantage 免费 Key（alphavantage.co 免费申请，每天 25 次，每只股票结果存 3 天）才会显示 E；不填只显示 D 和 S
- 画线按品种自动保存在本机浏览器，换周期不会丢
- 自选列表：
  - 可以建多个列表（右侧顶部的下拉框切换；＋ 新建、✎ 改名、🗑 删除）
  - 列表里可以分板块：点「＋板块」新建；点板块标题收起/展开；鼠标移上去有 ✎ 改名、× 删除（删板块不会删里面的股票）
  - 拖动可以排序，也可以把股票拖到别的板块；拖板块标题会连同里面的股票一起移动
  - 实时最新价和涨跌幅（加密货币是 24 小时，美股是对比昨收）。加密货币输入 `ADA` 会自动补成 `ADA-USDT`
- 警报：点顶部「🔔 警报」
  - 到价警报：填品种和价格，选「涨到 / 跌到」，可以只提醒一次（触发后自动关闭）或者每次穿过都提醒
  - 画线警报：先画一条水平线或趋势线并点选它，点左侧工具栏的 🔔 或在警报面板里「设警报」，价格穿过这条线就提醒（趋势线会向右延长）
  - 触发时：右上角弹窗 + 提示音 + 系统通知（第一次加警报时浏览器会问是否允许通知，选「允许」）；窗口标题前会出现 🔔
  - 程序开着才会提醒（关掉窗口就不会响）。看美股时，币的警报也照样在后台盯着，反过来也一样
  - 美股没打开「盘前盘后」时，只有常规时段的成交会触发警报

注意：画线、自选、警报和 API Key 都保存在打开程序的那个浏览器里。换一个浏览器，或者换一种方式打开，会得到一份新的空设置。

## 快捷键
- 直接打字（字母或数字）：弹出代码框，回车在当前图打开，↑↓ 选自选里的匹配项
- ← →：平移（按住 Shift 移得更多）；↑ ↓：放大缩小；End：回到最新；Home：重置缩放
- , 和 .：上一个 / 下一个周期；Shift+1…9：1分到月线，Shift+0：今年至今
- Tab / Shift+Tab：多图时切换当前图；Alt+1…5：切换 1 / 2 / 4 / 6 / 8 个图
- Alt+T 趋势线、Alt+R 射线、Alt+H 水平线、Alt+C 平行通道、Alt+B 矩形、Alt+F 斐波那契、Alt+X 斐波那契扩展、Alt+N 文字、Alt+M 测量
- Alt+A 警报、Alt+I 指标、Alt+S 筛选器；Delete 删除选中画线；Esc 取消；? 打开快捷键帮助
- Mac 上 Alt 就是 Option（⌥）键

## 警报推送到手机
在 ⚙ 设置里填 ntfy 主题、Discord Webhook 或 Bark 地址，点「发一条测试」确认能收到。警报触发时会同时推送。程序要开着才会推送。

## 备份
⚙ 设置最下面「导出备份」会在「下载」文件夹生成一个 guanchao-backup-日期.json。默认不包含 API Key 和推送地址，勾选后才包含（这样的文件不要发给别人）。「导入备份…」选这个文件即可恢复；备份里没有 Key 时会保留你现在的 Key。
