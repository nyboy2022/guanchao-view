美股数据：Alpaca API Key

在 alpaca.markets 免费注册后，在控制台生成 API Key。Key 只保存在你这台电脑的浏览器里，不会上传到别处。

美股实时（可选）：Tradier Token

有 Tradier 证券账户的话，填上它的 API Token，就能免费拿到全市场实时行情（含盘前盘后），黄圈 D 会消失。在 Tradier 网站登录后，到 Settings → API Access 复制 正式环境（Production）的 Access Token，不要用 Sandbox 的（Sandbox 是延迟数据）。同时填了 Alpaca Key 的话，更早的历史K线和分红拆股仍用 Alpaca。

警报推送到手机 / Discord（可选）

警报触发时，除了电脑上弹窗，还会推送到这里填的地方。填一个或几个都行，留空就不推。

ntfy 免费、不用注册：手机装 ntfy（iPhone / Android 都有），点 + 订阅这里的主题名。主题名谁知道谁就能收到，所以用「生成」的随机名字。也可以填完整地址，如 https://ntfy.sh/xxx。

在 Discord 频道设置 → 整合 → Webhook → 新建，复制网址贴到这里。

财报日（可选）：Alpha Vantage Key

分红和拆股直接用上面的 Alpaca Key，不用另外设置。财报日 Alpaca 不提供，需要在 alphavantage.co 免费申请一个 Key（每天 25 次查询，程序会把每只股票的结果存 3 天）。不填就只显示分红和拆股。

Key 的保存

Key 只存在这台电脑的浏览器配置里。双击「观潮看盘」打开时用的是单独的配置文件夹，和你平时的浏览器分开。同一个浏览器里打开的其它本地网页文件（file://）能读到这些设置，所以不要在里面打开来历不明的 .html 文件；和别人共用电脑的话，可以关掉下面的「记住」。
